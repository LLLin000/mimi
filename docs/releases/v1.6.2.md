## English

- Fixed incomplete translations and withdrawn recognition drafts being saved as confirmed subtitles, and improved original/translation pairing.
- Kept configuration drafts and retry actions when changing pages, pasting or recreating the Android interface. Unavailable services can no longer be selected.
- Improved local credential migration and configuration loading, including recovery after interrupted operations.
- Protected saved-session deletion and recording finalization. Changing Windows audio sources now clears the recording opt-in.
- Preserved the full macOS interface language, including regional variants.

Update from Settings → Software Update, or download the installer below. Portable Windows users can replace their existing executable after quitting Mimi.

## 中文

- 修复不完整译文、已撤回的识别草稿被保存为确认字幕的问题，改善原文与译文配对。
- 切换页面、粘贴或重建安卓界面后保留配置草稿和重试入口。不可用的服务无法再被选中。
- 改善本地凭据迁移和配置加载，包括中断后的恢复。
- 保护已保存会话的删除和录音收尾。Windows 切换音频来源时会清除录音勾选。
- 保留完整的 macOS 界面语言，包括地区差异。

可在「设置 → 软件更新」中更新，也可下载下方安装包。Windows 便携版请先退出 Mimi，再替换原有程序。
